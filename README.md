# 🗓 Університетський Розклад | Telegram Bot

Розумний та багатофункціональний Telegram-бот для зручного доступу до розкладу занять, інформації про викладачів та предмети. Бот також має вбудованого ШІ-асистента, підтримує інлайн-режим та вміє автоматично генерувати Google Calendar для кожної групи студентів.

## 🌟 Можливості

- 📅 **Гнучкий розклад:** Перегляд розкладу на день та тиждень з урахуванням "парних/непарних" тижнів.
- 🤖 **ШІ-Асистент (OpenAI):** Можливість спілкуватися з ботом природною мовою. ШІ розуміє контекст, знає розклад і може видавати інтерактивне меню з парами за запитом.
- 👨‍🏫 **Деталі про викладачів:** Фото, посада, контактні дані (Telegram, пошта, сайти).
- 📚 **Інформація про предмети:** Окремі посилання на Google Classroom / Moodle та кодові слова індивідуально для кожної групи.
- 🌍 **Часові пояси:** Підтримка налаштувань регіону для коректного відображення часу.
- 📆 **Інтеграція з Google Calendar:** Автоматична генерація `.ics` календарів розкладу для кожної групи, на які студенти можуть підписатися в 1 клік (оновлюються автоматично).
- 🔍 **Інлайн-режим (`@bot_username`):** Швидкий пошук та відправка розкладу будь-якої групи прямо в чати з іншими людьми.
- 👑 **Адмін-панель:** 
  - Глобальна розсилка повідомлень усім користувачам.
  - Скачування та завантаження локальної бази `db.json` "на льоту" (без перезапуску бота).
  - Генерація Google календарів в один клік.

## 🛠 Технологічний стек

- **Мова:** Python 3.10+
- **Фреймворк:** [Aiogram 3.3+](https://docs.aiogram.dev/) (Telegram Bot API)
- **AI Інтеграція:** `openai` (AsyncOpenAI 1.14+)
- **База даних:** Локальна JSON-база (`aiofiles` для асинхронного доступу)
- **Google API:** `google-api-python-client`, `google-auth` (для Google Calendar)
- **Конфігурація:** `pydantic-settings`
- **Деплой:** Docker, Docker Compose

## 🚀 Встановлення та запуск

### 1. Підготовка середовища
Склонуйте репозиторій та перейдіть у папку проекту:
```bash
git clone https://github.com/Yaroslavlazarenko/ScheduleBot.git
cd ScheduleBot
```

Створіть файл `.env` на основі прикладу та заповніть його:
```bash
cp .env.example .env
```
*(Вкажіть ваш `TELEGRAM_BOT_TOKEN`, а також ключі доступу до OpenAI: `API_KEY`, `BASE_URL`, `MODEL_NAME`).*

Переконайтеся, що файл `db.json` знаходиться в корені проекту. Якщо ви використовуєте генерацію Google Calendar, також покладіть файл `credentials.json` (ключ Service Account) у корінь.

---

### Варіант А: Запуск через Docker (Рекомендовано) 🐳
Це найшвидший спосіб розгорнути бота на сервері.

1. Переконайтеся, що у вас встановлені Docker та Docker Compose.
2. Запустіть контейнер у фоновому режимі:
```bash
docker-compose up -d --build
```
3. Перегляд логів бота:
```bash
docker-compose logs -f
```
4. Для зупинки бота використовуйте: `docker-compose down`

---

### Варіант Б: Локальний запуск (Для розробки) 💻
1. Створіть та активуйте віртуальне середовище:
```bash
python -m venv myenv
source myenv/bin/activate  # Для Linux/macOS
# myenv\Scripts\activate   # Для Windows
```
2. Встановіть залежності:
```bash
pip install -r requirements.txt
```
3. Запустіть бота:
```bash
python main.py
```

## 🔒 Призначення прав Адміністратора
Щоб отримати доступ до адмін-панелі (`👑 Адмін-панель`), вам потрібно змінити статус вашого користувача в файлі `db.json`. 
Знайдіть свій `telegram_id` у масиві `"users"` і змініть `"is_admin": false` на `"is_admin": true`. Після цього натисніть `/start` у боті, щоб оновити клавіатуру.
